# Reproducibility record

Article: Berna N. Yilmaz, "Architecture-Induced Tail Risk in Tokenized Assets:
Bridge Versus Native Settlement Designs in Voluntary Carbon Markets",
*Economics* (De Gruyter Brill), DOI [10.1515/econ-2025-0236](https://doi.org/10.1515/econ-2025-0236).

This file records the environment in which the published results were verified,
the mapping from each published table and figure to the script and output file
that produce it, and the differences a fresh run can be expected to show.

## 1. Verified environment

| Item | Value |
| --- | --- |
| Python | CPython 3.11.15 |
| Packages | `requirements-lock.txt` (exact versions of all 33 installed packages) |
| Operating system | macOS 27.0.1, arm64 (Apple M5) |
| Verification date | 30 October 2026 |
| Total runtime | about 3 minutes 45 seconds for the full pipeline |
| Random seeds | `SEED = 42` in every script that draws random numbers, through `numpy.random.default_rng` |

Setting up the same environment:

```bash
uv venv --python 3.11 env
uv pip install --python env/bin/python -r requirements-lock.txt
PY=env/bin/python bash run_all.sh
```

`requirements.txt` holds the same package versions without the transitive
dependencies and is enough for an ordinary run. `requirements-lock.txt` is the
exact set used for the verification reported here.

## 5. Result of the verification run, 30 October 2026

The pipeline was run from a clean copy of this repository in the environment of
Section 1, and the outputs were compared with the archived ones in `results/`.

- 28 CSV files compared. 16 are identical to the last bit. Ten differ only at
  the level of floating-point rounding, with a largest absolute difference of
  3e-13 and a largest relative difference of 8e-14.
- 13 generated LaTeX tables compared. Twelve are byte-identical. One differs by
  a single space inside `$\beta\approx 0.9$` in the caption, which typesets the
  same.
- Nine of the ten table files included in the manuscript are byte-identical to
  the freshly generated ones; the tenth is the caption spacing above.
- All 20 figure files included in the manuscript are identical to the archived
  copies in `results/figures/`. A fresh run reproduces 17 of them pixel for
  pixel. Two differ in about 1.8 % of pixels through text antialiasing alone,
  with identical plotted values (12.4 %, 13.5 %, 12.0 %, 11.0 %), and one
  differs by two to three pixels of canvas size because text extents vary
  slightly across font builds.

Two known deviations, neither of which affects a published value:

1. `results/tables/jump_events.csv` carries two rolling-volatility columns from
   an earlier run that annualized with 365 calendar days. The current code uses
   the 252-trading-day convention stated in the article, so a fresh run writes
   values smaller by a factor of sqrt(365/252) = 1.2039 in those two columns.
   The number of jump events, their dates, prices and returns are unchanged, and
   no published figure or table uses these two columns. Figure 1c regenerates
   pixel for pixel.
2. `results/tables/cross_market_correlation.csv` is an auxiliary check that the
   article does not report. Its p-values move in the fifth decimal place
   (1.3e-4) across SciPy builds.

Two points about the order of execution:

- `scripts/12_cross_market_correlation.py` downloads benchmark series
  (BTC-USD, ETH-USD, KRBN) from Yahoo Finance while it runs, so it needs
  network access and can be refused by rate limiting. `run_all.sh` therefore
  runs it last and treats a failure as a skipped step. No published result
  depends on it.
- `scripts/07_robustness_price_models.py` writes a preliminary version of
  `tab_robustness_models_R2.tex`, which `scripts/10_generate_latex_tables.py`
  then replaces with the version used in the article. Run the pipeline to the
  end, or that file stays in its preliminary five-column form.

## 6. Note on exactness

The simulations are seeded, so a given environment reproduces its own output
exactly. Differences at the level of 1e-13, and small differences in rendered
text, follow from the order of floating-point operations in BLAS and from font
rendering, and they vary across processors and library builds. Published values
are reported to three or four significant digits and are unaffected.

## 7. Changes after publication

The analysis code and the data are unchanged. The following corrections concern
usability only and are recorded here for transparency:

- `scripts/01_load_real_data.py` resolves its paths relative to the script, so
  it runs from any working directory; it detects the separator of the
  CoinMarketCap export, which is semicolon-separated; and it writes its parsed
  preview to `bct_loader_preview.csv` instead of overwriting the canonical
  cleaned series. This script is an optional helper. The published pipeline
  starts at script 02, which reads the raw export directly.
- `scripts/10_generate_latex_tables.py` accepts both the long and the wide form
  of `empirical_calibration.csv`, and the caption of Table 4 matches the
  published wording.
- `run_all.sh`, `requirements-lock.txt`, `.python-version` and this file were
  added.
